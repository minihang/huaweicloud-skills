# 训练策略与边界

## 证据和工程规则
本技能的具体范围受 ACSM 抗阻训练立场声明中“目标个性化、规律训练、不同负荷/训练量影响不同适应”等原则启发（出处：https://acsm.org/resistance-training-guidelines-update-2026/ ；原始声明：https://pubmed.ncbi.nlm.nih.gov/41843416/ ）。本技能不验证外部链接的当前有效性；链接失效或无法联网核验时，按本文档的保守规则执行，不向用户声称已核验原文。以下具体范围是可调整的实践起点；脚本5%降载、30秒延长休息、三次观察均是本产品工程启发式，不是该声明规定的统一处方，也没有证明优于真人教练。不要逐字复制来源长段落。

## 目标差异
|主目标|初始策略（不是固定处方）|重点评估|
|---|---|---|
|增肌|熟悉复合动作多用6—12次、辅助动作10—20次；从可恢复组数起步，按实际适应逐渐增加；复合动作休息约2—3分钟，辅助约1—2分钟|规范次数、负荷、可恢复周组数|
|最大力量|有经验且技术稳定后，主项可用3—6次、3—5分钟间歇；新手先练稳定动作，不测极限|相同动作下负重和技术稳定性|
|减脂保肌|保持可恢复的抗阻刺激和主项表现；疲劳时适度减量，不用短休息堆组追求消耗|力量维持、恢复、依从性|
|运动表现|先问服务何种表现；兼顾基础力量和动作质量，爆发练习仅在具备经验及条件时安排，速度明显下降即收组|专项相关表现、动作质量|
|综合体能|全身主要动作模式均衡覆盖，优先规律性、活动能力与可执行性|稳定参与和全身能力|

将大肌群一周约两次接触作为可协商起点，结合天数、分化与恢复安排。初学者可从每动作2—3正式组、RPE约6—7起步；有经验者按历史耐受设定，通常不默认每组力竭。RPE只指单组抗阻用力程度，不混用“整次训练RPE”。大致RPE 10=无法再完成规范重复、9≈还能1次、8≈2次、7≈3次；映射并不精确，新手可能估计偏差。先问“还能规范做几次”，允许不知道。

## 即时与周期调整
- 单组轻松且动作稳定：通常先在次数范围内增加次数或继续观察；后续满足目标再按器械最小档位进阶。不要随意建议10%以上跳重。上限不适合时优先加次数，不强迫加重。
- 高于目标强度、次数明显下滑：确认休息、动作和负重口径；延长休息、降低负重或减少剩余正式组。高位下拉后前臂酸不等于背阔肌完全疲劳，不仅凭“没感觉”增加大量动作。
- 只有30分钟：保留优先主项和必需热身，删次要重复模式；根据组数、动作执行时间、间歇和换器械时间估计可完成量，不把一小时方案硬塞进去。
- 连续可比训练达次数上限且强度和技术合适：考虑器械最小增量；连续困难：先排查睡眠、饮食、休息、动作和出勤，再讨论减量，不把所有停滞都归因于训练量太少。
- 保持核心动作一段时间以便比较；因疼痛、器械限制或长期不适配再替换，不每周随机换动作。恢复建议以睡眠规律、正常饮食、补水及训练间恢复为主，不给药物、极端节食或治疗方案。

## 动作选择、技术与替代
依器械和熟悉程度选择，不套固定动作库。相同模式替代也需重新校准负荷；机器数字、弹力带阻力、自重、辅助引体不能当成等价公斤数。常见示例：水平推（卧推→哑铃卧推/器械推胸）、水平拉（俯身划船→胸托划船/坐姿划船）、垂直拉（下拉→适合能力的辅助引体）、膝主导（深蹲→高脚杯深蹲/腿举）、髋主导（罗马尼亚硬拉→合适负荷的髋铰链变式）。这些是器械和模式替代，不是疼痛的治疗性替代。
首次提供站姿/躯干稳定、可控活动范围、避免代偿等与动作相关的2—3条具体提示。先用轻量活动升温，再给首个主要动作安排逐渐加重且不过度疲劳的热身组；之后按动作相似度补充热身。正式重量不明时先轻量试组，避免最大测试；无保护条件时不安排高风险力竭。

## 必须优先处理的情况
区分一般肌肉疲劳/延迟酸痛与尖锐疼痛、关节痛、突然无力或麻木。前者结合功能和表现保守调节，后者先停相关动作、澄清，不带痛尝试更大负重；持续或加重时建议专业评估。胸痛、晕厥、严重异常气短等危险症状停止整个训练并及时寻求急救帮助。不能通过文字诊断伤情或保证安全。未成年人、孕产期、术后、明确疾病/医疗运动限制需要相应专业指导，不直接套用健康成年人高强度计划。此边界只在相关情景简短说明，不每次回复重复免责声明。
